# Blood Donor Eligibility Pre-Screening System

## Overview
A beginner-friendly biomedical project developed using C. The program accepts basic donor information and checks it against configurable example criteria.

## Objectives
- Practise multiple-condition decision making.
- Use logical operators and conditional statements.
- Generate a simple donor pre-screening report.

## Parameters
- Age in years
- Weight in kilograms
- Hemoglobin in g/dL
- Days since the last donation

## Programming Concepts
- Variables and data types
- `scanf()` and `printf()`
- `if-else` statements
- Logical operators (`&&` and `||`)
- Input-based decision making

## How to Run
1. Open `main.c` in a C compiler.
2. Compile and run the program.
3. Enter the requested values.
4. Review the generated screening report.

## Limitations
- Uses simplified example criteria.
- Does not assess medical history, medications, infections, or other donor-safety factors.
- Does not replace a blood-bank screening process.
- Does not determine actual eligibility to donate blood.

## Disclaimer
This program is for educational purposes only. The criteria are illustrative and are not official eligibility rules. Actual donor eligibility must be assessed by qualified blood-bank personnel according to applicable guidelines.
